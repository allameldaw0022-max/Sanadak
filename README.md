# سندك (Sanadak)

منصة سودانية مستقلة للتحقق من الأجهزة (device verification) وتوثيق ملكيتها.
تساعد سندك أي شخص على فحص جهاز جوال قبل شرائه، تسجيل جهازه الخاص، توثيق
ملكيته، الحصول على شهادة ملكية قابلة للتحقق العلني، والإبلاغ عن الأجهزة
المفقودة أو المسروقة.

الموقع الرسمي (Production): **[sanadk.men](https://sanadk.men)**

## ما تقدمه المنصة

- فحص رقم **IMEI** مجانًا لأي زائر دون الحاجة لحساب.
- تسجيل الأجهزة على حساب المستخدم.
- تقديم ومراجعة **مطالبات ملكية** للأجهزة، مع رفع أدلة إثبات الملكية.
- تقديم **بلاغات فقدان أو سرقة** للأجهزة.
- إصدار **شهادات ملكية** رقمية قابلة للتحقق العلني.
- التحقق من الشهادات عبر مسح رمز **QR** (بما في ذلك ماسح QR مدمج داخل
  المنصة نفسها) أو عبر إدخال معرّف الشهادة يدويًا.
- حسابات مستخدمين بأدوار مختلفة (مستخدم عادي، تاجر، مشرف).
- **لوحة إدارة** لمراجعة المطالبات والبلاغات وإدارة المستخدمين والاشتراكات.
- **نظام إشعارات** داخلي للمشرفين عند وجود طلبات أو بلاغات جديدة.
- **نظام اشتراكات للتجار** (خطط، طلبات اشتراك، مراجعة إدارية).
- تسجيل **أحداث أمنية (Security Events)** وتطبيق **تحديد معدّل الطلبات
  (Rate Limiting)** على المسارات الحساسة والعامة.
- نسخة **Android** مبنية كتطبيق TWA (Trusted Web Activity) للموقع نفسه.

## رحلة الاستخدام الأساسية

1. فحص الجهاز عبر رقم IMEI (متاح للجميع بدون تسجيل دخول).
2. تسجيل الدخول عند الحاجة لإجراء يتطلب حسابًا.
3. تسجيل الجهاز على حساب المستخدم، أو تقديم مطالبة ملكية لجهاز مسجَّل مسبقًا.
4. تقديم أدلة إثبات الملكية عند الحاجة (صور أو مستندات).
5. مراجعة المطالبة من قبل فريق الإدارة.
6. إصدار شهادة الملكية عند استيفاء الشروط.
7. التحقق من الشهادة لاحقًا (من قبل أي شخص) عبر مسح رمز QR أو إدخال معرّف
   الشهادة يدويًا.

## الأمان والخصوصية (Security & Privacy)

- رقم IMEI الكامل **لا يُكشف للعامة**؛ نتائج الفحص والشهادات العامة تُظهر
  فقط الحالة/الماركة/الموديل وتاريخ الإصدار، دون رقم IMEI الكامل أو هوية
  المالك.
- يُخزَّن رقم IMEI بصيغة **مجزّأة (hash) آمنة**، ولا يُستخدم كنص خام في
  عمليات المطابقة.
- صلاحيات الوصول للبيانات تعتمد على **المصادقة (Auth)** وسياسات
  **Row Level Security (RLS)** على مستوى قاعدة البيانات، بحسب دور كل
  مستخدم (مستخدم عادي، تاجر، مشرف).
- شهادة الملكية العامة القابلة للتحقق لا تكشف معلومات حساسة مثل رقم IMEI
  الكامل أو هوية المالك.
- تطبَّق آليات **Rate Limiting** وتسجيل **أحداث أمنية (Security Events)**
  على المسارات الحساسة والعامة (مثل التحقق من الشهادات).

> لا يحتوي هذا الملف على أي أسرار أو مفاتيح API أو قيم بيئة فعلية، ويجب ألا
> يحتوي أي تحديث مستقبلي له على ذلك.

## ملاحظات مهمة

- سندك **منصة مستقلة**، وليست جهة حكومية أو تابعة لأي جهة رسمية.
- تسجيل جهاز أو إصدار شهادة على المنصة **لا يمثل حكمًا قضائيًا نهائيًا**
  على ملكية الجهاز.
- مراجعة المطالبات والبلاغات تعتمد على البيانات والأدلة المقدَّمة من
  المستخدم، وليست تحقيقًا رسميًا شاملاً.
- تهدف المنصة إلى زيادة الثقة وتقليل مخاطر شراء أجهزة مجهولة المصدر، وهي
  **ليست ضمانًا مطلقًا** ضد الاحتيال أو السرقة.

## التقنيات (Tech Stack)

- **Next.js** (App Router) + **TypeScript**
- **Tailwind CSS**
- **Supabase** — قاعدة البيانات، المصادقة (Auth)، والتخزين (Storage)، بحسب
  ما هو مستخدم فعليًا في كل جزء من المشروع
- **qrcode** / **qr-scanner** — توليد رموز QR للشهادات ومسحها للتحقق
- **lucide-react** للأيقونات
- دعم كامل للغة العربية RTL، وتصميم Mobile First متجاوب
- **Vitest** للاختبارات
- نسخة **Android** كتطبيق TWA (Trusted Web Activity) لنفس الموقع

## هيكلة المشروع

```
src/
  app/                 صفحات المشروع (Next.js App Router) والمسارات العامة
                       والخاصة بالمستخدم، التاجر، والإدارة
  components/          مكوّنات واجهة قابلة لإعادة الاستخدام (layout, ui,
                       admin, auth, devices, home, ...)
  lib/                 دوال ومنطق مساعد: الأمان (security)، الشهادات
                       (certificates)، الأجهزة (devices)، المصادقة (auth)،
                       عميل Supabase، والرفع (uploads)
supabase/
  migrations/          ملفات ترحيل قاعدة البيانات (SQL)
android/                مشروع Android (TWA) الخاص بتطبيق سندك
```

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000) في المتصفح.

### أوامر أخرى

```bash
npm run build   # بناء نسخة الإنتاج
npm run start   # تشغيل نسخة الإنتاج
npm run lint    # فحص الكود
```
